[PROJECT_OVERVIEW]
Aotopo is a high-performance React web application built with Vite for an independent band from Guarulhos/SP. It serves as a digital identity, featuring a home page with "Hero" and "About" sections, social media integration, and a future shop. The project follows a strict architectural boundary between structure (JSX) and behavior (Hooks), uses a semantic Design System through Vanilla CSS, and maintains a highly organized component folder structure.

[FOLDER_TREE]
src/
  assets/ (Global images/icons like allBand.webp, logo-textura.png)
  components/ (Reusable UI Atoms/Molecules)
    button/ (Universal Action Component)
    header/ (Responsive Multi-layer Header)
      desktop/ (Desktop-specific layout)
      mobile/ (Drawer-based mobile layout)
    icon/ (SVG Icon Library)
    logo/ (Brand Logo Variants)
    text/ (Design System Typography Engine)
  helpers/ (Utilities like links.js)
  pages/ (Route-level Views)
    home/ (Main landing page)
      about/ (Band history section)
      hero/ (Main visual entry)
    shop/ (Future store area)
  styles/ (Global CSS and Tokens)
    root.css (Design Tokens / CSS Variables)
    global.css (Global resets and base styles)
  App.jsx (Main Orchestrator)
  main.jsx (Entry Point)

[PATH_ALIASES]
- @components -> src/components (Primary for reusable UI)
- @pages      -> src/pages      (Primary for page sections)
- @helpers    -> src/helpers    (Primary for shared logic/data)
- @assets     -> src/assets     (Primary for static media)

[IMPORT_PATTERNS]
Always use absolute aliases for better refactoring:
- import Text from "@components/text/component"
- import Icon from "@components/icon/component"
- import links from "@helpers/links"
- import About from "@pages/home/about/component"

Local imports (hooks/styles) stay relative:
- import "./style.css"
- import { useAbout } from "./useAbout"

[ARCHITECTURE & LOGICAL SEPARATION]
MANDATORY RULE: Never mix behavior and markup in the same file.
1. component.jsx: Strictly for JSX, Props, and simple rendering logic.
2. useComponentName.js: A custom hook containing ALL state, useEffects, event listeners (scroll, resize), business logic, and complex calculations.
3. style.css: Scoped styles following BEM conventions.

[COMPONENT TUTORIAL: THE TYPOGRAPHY ENGINE (Text)]
The @components/text/component is the most critical atom. It provides:
- Props: size (xs to 10xl, heroTitle), weight (regular to bold), color (default, subtle, muted, inverted, orange, blue, ocean), font (principal, display), align, lineHeight, truncate, uppercase, hoverEffect.
- Variants: Text.H1, Text.H2, Text.H3, Text.P, Text.A (automatically set semantic tags and default styles).
Usage: <Text.H2 color="orange" weight="bold">QUEM SOMOS</Text.H2>

[COMPONENT TUTORIAL: THE ICON SYSTEM (Icon)]
- File: @components/icon/icons.jsx contains the raw SVG paths.
- File: @components/icon/iconList.md lists all available models.
- Usage: <Icon model="instagramOutlined" size="md" color="var(--color-orange)" />

[COMPONENT TUTORIAL: BRANDING (Logo)]
- Hook-driven variant selection via @components/logo/logomap.js.
- Variants: brancoSf, pretoSf, brancoTexturaSf.
- Usage: <Logo variant="brancoSf" size="xs" />

[COMPONENT TUTORIAL: ACTIONS (Button)]
- Polymorphic: Automatically becomes <a> if href is present, otherwise <button>.
- Features: loading, disabled, variants (filled, etc).
- Usage: <Button variant="filled" href={links.youtube}>VER VÍDEOS</Button>

[UTILITY: LINKS HELPER]
The @helpers/links.js file is the SINGLE SOURCE OF TRUTH for external URLs:
- links.youtube
- links.instagram
- links.tiktok
Always import this instead of hardcoding URLs in components.

[STYLING SYSTEM & DESIGN TOKENS]
Defined in src/styles/root.css. Always use var() for:
- Spacing: --spacing-1 (4px) to --spacing-32 (128px).
- Colors: --color-orange, --color-blue, --color-ocean, --color-master (with darker/light scales).
- Fonts: --font-family-principal (Segoe UI), --font-family-display (Impact).
- Radius: --radius-1 (4px) to --radius-pill.
- Z-Index: --z-base to --z-tooltip (1600).

[CONSTRAINTS]
- NO Tailwind or UI Libraries. Vanilla CSS only.
- BEM Naming: .block__element--modifier (e.g., .header__menuItem--active).
- Semantic HTML: Use <section>, <nav>, <article>, <header> correctly.
- Responsiveness: Order styles by Mobile-First or explicit @media (max-width) blocks at the bottom of .css files.
- Interactivity: All UI feedback (hover, focus) must be smooth and use project colors.

[AI OPERATIONAL GUIDE]
When building or modifying:
1. Identify the architectural boundary.
2. If adding behavior, create/update the Hook.
3. If adding markup, use the Design System components (Text, Button, Icon).
4. Verify root.css for existing tokens before creating new ones.
5. Update this file after any structural change.
