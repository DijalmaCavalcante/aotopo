[PROJECT_OVERVIEW]
Aotopo is a React-based web application for an independent band from Guarulhos/SP. The project follows a component-based architecture with strict logic separation and BEM-like styling conventions.

[FOLDER_TREE]
src/
  assets/
  components/
    button/
    header/
    icon/
    logo/
    text/
  helpers/
  pages/
    home/
      about/
      hero/
    shop/
  styles/

[PATH_ALIASES]
@components -> src/components
@pages -> src/pages
@helpers -> src/helpers
@assets -> src/assets

[IMPORT_PATTERNS]
import Component from "@components/button/component"
import Header from "@components/header/component"
import links from "@helpers/links"
import useHero from "./useHero"

[ARCHITECTURE]
Component-based architecture. Logic (state, effects, events, calculations) MUST be isolated in custom hooks (use[ComponentName].js) within the component folder. JSX files remain declarative.

[COMPONENT_STRUCTURE]
/component-folder
  component.jsx
  style.css
  use[ComponentName].js
  readme.md

[STYLING_SYSTEM]
Vanilla CSS with CSS variables. BEM-like naming (component__element--modifier). No utility-first frameworks.
