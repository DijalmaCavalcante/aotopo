[PROJECT_OVERVIEW]
Aotopo is a React-based web application for an independent band from Guarulhos/SP. The project follows a component-based architecture with clear logic separation and styling conventions.

[FOLDER_TREE]

[ARCHITECTURE]
The project uses a component-based architecture where each component is contained in its own folder. Logic is often separated into custom hooks (e.g., useButton.js, useAbout.js). Pages are composed of these components.

[COMPONENT_STRUCTURE]
Each component folder typically contains:
- component.jsx: The React component
- style.css: Scoped styles
- use[ComponentName].js: Logic hook (optional)
- readme.md: Documentation (optional)

[STYLING_SYSTEM]
Vanilla CSS with CSS variables defined in root.css. Global styles in global.css. BEM-like class naming conventions are used (e.g., component__element--modifier).

Colors: orange-darker, orange-dark, orange, orange-light, orange-lighter, orange-lightest, blue-darker, blue-dark, blue, blue-light, blue-lighter, blue-lightest, ocean-darker, ocean-dark, ocean, ocean-light, ocean-lighter, ocean-lightest, master-darker, master-dark, master, master-light, master-lighter, master-lightest, pure-white, pure-black.
