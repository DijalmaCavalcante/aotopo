[PROJECT_OVERVIEW]
Aotopo is a high-visual-impact React application for the band Ao Topo, built with Vite and focused on strict architectural separation and aesthetic polish.

[FOLDER_TREE]
src/
  assets/
  components/
    button/
    header/
      desktop/
      mobile/
    icon/
    logo/
    text/
  helpers/
  pages/
    home/
      about/
      hero/
  styles/

[PATH_ALIASES]
@components -> src/components
@pages -> src/pages
@helpers -> src/helpers
@assets -> src/assets

[IMPORT_PATTERNS]
import Component from "@components/name/component"
import Icon from "@components/icon/component"
import link from "@helpers/links"
import "./style.css"

[ARCHITECTURE]
- Source of truth: .gemini/ directory for rules and commands.
- Component Isolation: Each component is a folder containing component.jsx (UI) and style.css (BEM).
- Logic Separation: State and logic must be in use[Name].js hooks, imported into component.jsx.
- Header System: Split into desktop and mobile versions for responsive control.

[COMPONENT_STRUCTURE]
- component.jsx: Declarative JSX only.
- style.css: Localized BEM styles.
- use[Name].js: Business logic, state, and event handlers.
- readme.md: Component documentation.

[STYLING_SYSTEM]
- Pure CSS: No Tailwind or utility frameworks allowed.
- BEM-Aotopo: [folderName]__[elementCamelCase]--[modifier].
- Text Component: Centralized typography management via props (size, weight, color, font, hoverEffect).

[ROOT_VARIABLES]
- Spacing: --spacing-0 to --spacing-32 (4px increments).
- Colors: orange, blue, ocean, master (darker to lightest scales).
- Typography: --font-size-xs to --font-size-heroTitle (11rem).
- Fonts: principal (Segoe UI), display (Impact).
- Radius: --radius-1 to --radius-pill (9999px).
- Z-Index: --z-base to --z-tooltip.

[PATTERNS]
- Interactive elements use transition: 0.2s for smoothness.
- Icons are centralized in @components/icon/ and documented in iconList.md.
- Social links are centralized in @helpers/links.js.

[BUSINESS_RULES]
- JSX files must remain declarative; NO complex logic inside component.jsx.
- All styles must use design tokens (CSS variables) from root.css.

[CONSTRAINTS]
- NO inline styles.
- NO utility-first CSS.
- Files must follow camelCase; Components use PascalCase in imports.

[DEPENDENCIES]
- React (Vite)
- Standard CSS Custom Properties
